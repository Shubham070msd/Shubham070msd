## 🔥 War Stories — Real Prod Incidents

> *The incidents that made me a better engineer*

**🔴 P1 — MongoDB CPU 100%, Gaming Platform Down · 3AM**
> Players dropping mid-game. Identified missing index on high-frequency query via slow logs. Added compound index → CPU dropped from 100% to 18% in 3 minutes. Added Zabbix query performance alerts so it never sneaks up again.

**🟠 P2 — DDoS on Crypto Wallet API**
> Traffic spike took API response from 80ms → 8s. Deployed Cloudflare WAF rate limiting, blocked malicious IPs, implemented request fingerprinting. Service restored in under 15 minutes. Zero data loss.

**🟠 P2 — Bad Deploy Crashed Casino Game Servers**
> Config change pushed to prod without validation. Rolled back in 4 minutes via Jenkins. Added mandatory staging smoke tests to pipeline. Deploy failures dropped 50% after.

**🟡 P3 — Backup Script Silently Failing for 18 Days**
> Script exiting with code 0 even on failure — no alerts triggered. Rewrote with proper exit handling, checksum validation, and daily backup verification cron. Now it *proves* it worked, not just that it ran.
